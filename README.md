# 📒 Address Book Management System in C

## 📌 Overview

The Address Book Management System is a console-based application developed using the C programming language. It helps users efficiently manage contact information by providing operations such as adding, searching, editing, deleting, and displaying contacts.

The project uses structures, arrays, modular programming, and file handling concepts to organize and maintain contact details.

## ✨ Features

- **Add Contact:** Add new contacts with name, phone number, and email address.
- **Search Contact:** Search for contacts using available search criteria.
- **Edit Contact:** Modify the details of existing contacts.
- **Delete Contact:** Remove unwanted contacts from the address book.
- **List Contacts:** Display all stored contacts.
- **Sort Contacts:** Sort contacts based on name, phone number, or email address. 
- **File Handling:** Store and retrieve contact information using files.
- **Data Persistence:** Maintain contact information across multiple program executions.

## 🛠️ Technologies Used

- Programming Language: C
- Concepts: Structures, Arrays, Functions, Pointers
- File Handling: File I/O operations
- Compiler: GCC
- Development Environment: Linux / Ubuntu

Compile the project using GCC:

```bash
gcc main.c contact.c file.c populate.c -o addressbook
```

## ▶️ Execution

Run the compiled application:

```bash
./addressbook
```
